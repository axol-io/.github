# axol.io

Open security infrastructure for Ethereum.

Four people: two former Blockdaemon node operators, a former DOJ/FBI financial intelligence analyst, and an active Immunefi whitehat. We run validators on Ethereum (StakeWise, CSM, Lido SDVT, Obol/SSV) and 18 other chains.

We maintain a zero-knowledge compliance standard, open cryptographic primitives, an Ethereum execution client in Elixir, and a vulnerability research practice.
